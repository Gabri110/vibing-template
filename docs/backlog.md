# Backlog

Lo pendiente que sale de una tarea y no es de esa tarea, con contexto suficiente para entenderlo
sin la conversación delante. Si cae en la zona de otra persona, se apunta aquí y se le avisa, en
vez de tocarlo de pasada.

Formato: `- [ ] AAAA-MM-DD · zona · qué falta y por qué (de dónde sale)`.
